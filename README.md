# NeuroHome — P300 EEG Smart-Home Prototype

## Exact appliance mapping
- Run 1 → Television
- Run 2 → Telephone
- Run 3 → Lamp
- Run 4 → Door
- Run 5 → Window
- Run 6 → Radio

The Smart Home frontend always displays **all six appliances**. At startup the count is **0 / 6**. A successful accepted Target changes only the appliance assigned to that run.

**Important:** Run 5 controls **Window only**. It does not control Lamp.

No Laptop, no scene control, no multi-device action, no peak selection, and no manual appliance controls.
